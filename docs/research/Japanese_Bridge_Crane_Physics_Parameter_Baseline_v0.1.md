# 日式渡橋機訓練模擬器：物理參數研究基準 v0.1

日期：2026-09-11  
狀態：正式物理模型開發前的研究與校準基準  
適用範圍：上重下輕的盒裝 Figure、兩條平行圓桿、雙爪日式橋渡設定、iPhone 橫向網頁訓練模擬器

## 1. 結論

目前證據足以建立一個遵守剛體力學的「可校準原型」，但不足以聲稱已精確複製影片中某一部 Taito 原廠機。影片拍攝地點／裝潢可能屬 Taito 類型機舖，但機頭貼紙遮蓋原廠標識，現階段不能可靠確認實際機台型號。

以下數值分為：

- **確定值**：物理常數、影片檔案資料或官方資料。
- **影片推算**：由畫面比例、時間與物件運動反推。
- **工程初值**：用來啟動模擬及敏感度測試，不代表實機設定。
- **待量度**：沒有足夠證據，不應假稱為準確值。

正式模型必須保存每次運算的完整參數；不得使用隱藏成功率、預設翻盒動畫、額外吸力或無限馬達力修正結果。

### 質量模型要求

盒不可只使用均勻長方體密度。建議以一個紙盒外殼碰撞體，加 2–4 個不可見的內部質量塊描述 Figure、底座及包材，再由下式計算合成重心：

`r_COM = Σ(mᵢ rᵢ) / Σmᵢ`

轉動慣量必須由相同質量分布計算，不能只移動重心但保留均勻盒慣量。否則翻轉速度會錯。

### 爪的物理要求

專利 S3 表明爪由致動器產生有限閉合力，而且反向外力超過致動器吸力時會令爪失去抓力。因此模型應使用**力／力矩限制的關節馬達**，不能把爪臂位置直接動畫到指定角度。受阻時，目標角度與實際角度可以不同。

## 7. 影片中的基準場景

S1 第二段可建立三個驗收場景。時間為錄屏時間，受剪接影響，只用於定位畫面：

| 場景 | 約略時間 | 觀察 | 模型必須重現的物理特徵 |
|---|---|---|---|
| V1：上重下輕初始狀態 | 01:07–01:10 | 盒直立／近直立；字幕明示上重下輕 | 重心固定在盒本體上方區域；靜止時由桿接觸提供平衡反力 |
| V2：落位太前失敗 | 01:10–01:16 | 爪接觸後未形成有效出貨姿勢；字幕標示「太前…失敗」 | 有碰撞和少量移動，但重心投影未越過有效支撐邊界；不得強制翻盒 |
| V3：較後接觸形成出貨 Pose | 01:18–01:25 | 後移落點後盒快速翻成斜橋姿勢 | 爪接觸力對支點產生力矩；盒的高重心放大角加速度；其中一端轉動／滑動而非整盒平移 |
| V4：後續推進至跌落 | 01:25–01:42 | 盒逐步旋轉及失去支撐，最終跌入出口 | 只有當重心垂直投影越過剩餘接觸支撐區、且摩擦無法保持平衡時才跌落 |

## 8. 必須遵守的物理條件

1. 每一影格／物理步均滿足牛頓—歐拉剛體方程；角加速度由慣量張量及合力矩求得。
2. 靜摩擦滿足 `|F_t| ≤ μs N`；超過上限才轉為滑動摩擦。
3. 翻倒由重心投影、接觸幾何與力矩自然產生；不得使用「角度超過 X 即跌落」的遊戲規則。
4. 爪、桿、盒均使用有厚度的碰撞體；盒角及爪尖需有合理小圓角，避免數值奇點。
5. 爪為有限力矩關節；撞桿或盒時可以停、偏移、滑脫或未完全閉合。
6. 盒的重心與慣量跟隨本體旋轉；不可把「上重心」理解為世界座標永遠向上。
7. 不同畫面 FPS 下必須使用相同固定物理步長；建議物理更新 120 Hz，必要時啟用 CCD。
8. 模擬不能憑空增加機械能；唯一能量輸入來自重力、爪關節馬達及機頭運動。

## 9. 驗證矩陣

| 測試 | 方法 | 合格準則 |
|---|---|---|
| 自由落體 | 從已知高度釋放測試盒，關閉空氣阻力 | 位移／速度與解析解誤差 ≤ 1%（碰撞前） |
| 靜止支撐 | 盒平放於兩桿 10 秒 | 無可見漂移；位置變化 ≤ 1 mm；無持續抖動或能量增加 |
| 摩擦臨界角 | 緩慢增加測試平面角度 | 開始滑動角與 `atan(μs)` 相差 ≤ 1° |
| 純力矩翻倒 | 在已知高度水平施力 | 翻倒閾值與靜力力矩計算相差 ≤ 5% |
| 爪受阻 | 以固定障礙阻止爪完全閉合 | 爪停止／達力矩上限；不得穿模；接觸力不得超出設定峰值 5% |
| 桿上滑動 | 已知重量及拉力拖動盒 | 動摩擦加速度與 `F = ma` 預測相差 ≤ 5% |
| FPS 不變性 | 30、60、120 FPS 重播同一輸入 | 最終位置差 ≤ 3 mm；角度差 ≤ 1.5°；成功／失敗結果一致 |
| V2 失敗場景 | 重建影片的前置落點 | 同一參數集下保持失敗；不得進入 V3 出貨姿勢 |
| V3 成功姿勢 | 只改落爪位置，不改物理參數 | 自然翻成斜橋姿勢；方向與影片一致 |
| 保留片驗證 | 用沒有參與調參的另一爪影片 | 不修改參數仍能合理預測移動／旋轉方向及成敗 |

## 10. 校準優先次序

正式物理模型前，建議依以下次序縮窄參數；次序錯誤會令不同參數互相補償而產生假準確：

1. 盒及桿的實際幾何。
2. 盒總質量與三維重心。
3. 紙盒—桿及爪尖—紙盒摩擦。
4. 爪臂關節幾何、開合範圍及機頭路徑。
5. 爪力—開口角曲線。
6. 回彈、關節阻尼及其他次要數值。
7. 最後才調整渲染、鏡頭震動、音效及機舖氣氛。

## 11. 開發准入條件

在開始正式物理模型前，至少要接受以下限制：

- 目前可先使用表內建議初值製作校準原型。
- 未有實物量度前，盒重量、尺寸、桿距、摩擦及爪力仍屬低可信度。
- 原型 UI 必須顯示目前參數、來源等級及是否經過校準。
- 只有通過第 9 節的解析測試及影片保留片驗證，才可標示為「物理驗證版」。
- 在未識別原廠型號及量度營運設定前，不可標示為「Taito 官方／精確模擬」。

## 12. 下一輪最有價值的證據

若日後可以取得其中任何一項，參數可信度會顯著提高：

1. 同一部機沒有剪接的完整一局正面影片。
2. 同步側面影片，或在玻璃外放直尺／已知尺寸標記。
3. 同款 Figure 未開盒的三軸尺寸、整盒重量及四面平衡點。
4. 圓桿直徑、中心距與高度差。
5. 用薄型壓力計量不同開口角的單邊爪力。
6. 機台內部銘牌、設定畫面或維修手冊，以確認真正型號與控制方式。
